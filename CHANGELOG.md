# Changelog

## [0.1.0] - First public release

### Added

- Offline-first manual trade journaling with local Room storage.
- Options, Futures, Equity and Other trade records.
- Default NIFTY, BANK NIFTY, SENSEX, NSE and BSE catalogs.
- Searchable and customizable symbols, exchanges and lot sizes.
- Options strike, expiry, lot-size and quantity workflows.
- Entry, Exit, Stop Loss, Target, Charges, Buy/Sell and Call/Put fields.
- Live gross and net P&L preview with regression-tested calculations.
- Trade history with details, editing and deletion.
- Daily and weekly reviews.
- Performance analytics for P&L, profit factor, drawdown, expectancy and tags.
- CSV import/export and JSON backup/restore.
- Device-local chart screenshot attachments.
- Light, Dark and AMOLED Black themes.
- Floating navigation dock with animated active destinations.
- GitHub Actions test/build CI and tag-driven APK release automation.
